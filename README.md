# Teja Meragala — Portfolio

A responsive, dark, hybrid-style personal portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser, or run a local server from this folder:

```bash
python -m http.server 8000
```

Then visit http://localhost:8000.

## Deploy free with GitHub Pages
1. Create a new public GitHub repository, for example `teja-portfolio`.
2. Upload the contents of this folder (not the enclosing ZIP).
3. In GitHub, open **Settings → Pages**.
4. Select **Deploy from a branch**, choose `main` and `/ (root)`, then Save.
5. Your site will be published at `https://YOUR-USERNAME.github.io/teja-portfolio/`.

## Personalisation before publishing
- Check that all internship descriptions and certificate names match your records.
- The Credentials section includes five saved certificate/selection-document previews; click a preview to open the image.
- The hero section uses the portrait photo previously uploaded in your files.
- Additional resume-listed credentials remain text-only where an original image was not found in the saved files.
- A CSC certificate image found in the archive named a different recipient and was intentionally excluded.
- The resume PDF is included in `assets/` if it was available when this package was generated.

## Files
- `index.html` — page content and links
- `styles.css` — responsive styling and animations
- `script.js` — mobile navigation, type animation and scroll reveals
- `assets/` — resume, portrait, project visuals, and certificate images


## Run the Language Translation Tool locally
The hosted Streamlit demo is not linked in the portfolio while its availability is uncertain. To run the source project on Windows:

1. Install Python 3.10+ and Git.
2. Clone the repository: `git clone https://github.com/tejameragala-ops/CodeAlpha-Task-1.git`
3. Open the project folder in PowerShell or VS Code terminal.
4. Install the app dependencies: `python -m pip install streamlit deep-translator gTTS`
5. Start the app: `python -m streamlit run app.py`
6. Open the local URL printed in the terminal (normally `http://localhost:8501`).

If the repository contains a `requirements.txt`, use `python -m pip install -r requirements.txt` instead of step 4.
